# Duplicate-aware search

Returning any match is legitimate when the supplied contract permits it. A passing original suppresses this component's repair proposals. For an endpoint-valued search, the engine can remove an early midpoint return and direct equality into the appropriate half of a shrinking interval. For an ordinary search with an externally specified first or last exact match, it can refine a found position with a checked adjacent scan, retaining the original absent result.

The evaluation includes leftmost exact match, one-past-end upper insertion, saturated lower bound, ordinary equality, empty logical length and singleton controls. An insertion at extent and a sentinel for absence have distinct evidence.

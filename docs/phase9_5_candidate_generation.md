# Candidate generation

The new search admits one edit per candidate, at most 24 trials and at most
four emitted proposals. The CFG model caps a function at 85 reachable
blocks, three loops, 64 entered points per loop and sample, and 32 fixed
cells. Each sample has a shared 650-transfer cap. Existing time limits apply.

The candidate gate reuses the original source, deterministic ranking and
compiler validation. Manual approval still applies to the complete reviewed
candidate. Earlier coordinated repairs retain their atomic edit behavior.

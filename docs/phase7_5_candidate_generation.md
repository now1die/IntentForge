# Candidate generation

| Category | Evidence |
| --- | --- |
| `RECURSIVE_DEPENDENCY_PROGRESS` | Guarded argument passed unchanged into a self-call in the return slice |
| `NONUNIT_RECURSIVE_PROGRESS` | A scalar progress relationship and multiple typed examples entering the recursive branch |
| `RECURSIVE_TERM_COMBINATION` | Two recursive terms traced through distinct local definitions |
| `HELPER_ARGUMENT_DEPENDENCY` | Repeated contributing position and an independently varied unused input |
| `RADIX_PROGRESS_MISMATCH` | The same quotient binding disagrees with a remainder radix or a threshold-linked scale |

All new alternatives use one edit. Proposals have source spans, evidence and counter-evidence, and pass the shared compiler validation and deduplication. Phase 7.5 adds at most six proposals before the existing total attempt cap. The final cohort produced one code-only and 54 guided alternatives, with all 54 guided candidates compiler-valid. The unchanged gateway runs up to four candidates per request.

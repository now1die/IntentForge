# Compiler workspace

Select Mini-C or Full C, edit the source in Monaco and choose **Analyze Code**. Mini-C displays lexical, syntax and semantic results. Diagnostic actions select the actual line. **Find compiler fixes** runs the existing correction workflow. Open **Fixes** to review the suggested change, select a different validated option or validate a custom edit.

**Overview** summarizes functions and scoped variables from compiler data and shows the bounded Mini-C CFG when available. **Tokens**, **AST**, **Symbols**, **Diagnostics** and **Fixes** retain the existing views. Full C uses Clang analysis on installations with Clang available. [Feature inventory](phase14_feature_migration.md)

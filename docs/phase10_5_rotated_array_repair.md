# Rotated array repair

The model recognizes a fixed interval with midpoint and upper-endpoint reads over the same local array, and a branch that moves either endpoint. Trusted discovery outputs must agree with the minimum position on complete, distinct ordered rotations, including unrotated cells. The candidate may correct direction and add one to the lower-latch midpoint. The two edits share a strict-shrink obligation and are reviewed together.

The three-cell injected defect and two-cell regression exercise the bounded repair. Duplicate cells are covered by controls, and ambiguous rotated duplicates do not justify this candidate family. The archived short-rotation defect remains unsupported because its neighbor-based three-way control flow needs guard and interval changes beyond this model.

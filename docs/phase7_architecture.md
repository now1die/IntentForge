# Phase 7 architecture

Engine 7 opts in to Phase 6.5 generation with a guarded-CFG recognizer and bounded scalar-helper summaries. Static examples mode accepts function name and typed expectations. It labels candidate hypotheses as possible repairs while verification is unavailable. The static endpoint compiles proposals within the existing attempt budget.

The local gateway sends the exact source, entry point, tests and at most four candidate programs to the same restricted worker under private profile 7. Once identities are validated, the gateway classifies original behavior, review eligibility and per-pair observations. Static and behavioral ranking remain visible. The Phase 7 response schema extends the prior response only for engine 7.

# Candidate generation

| Category | Edit |
| --- | --- |
| Logical empty result | Replace a direct return read on a proven empty branch with the sample-supported result |
| Sentinel presence | Replace an equality or inequality check with the existing closed-protocol Boolean flag |
| Independent coordinates | Extend an existing signed bounds guard with the other independent axis |

Each category emits a one-site edit. Existing trial, proposal and global validation caps remain in effect. Three distinct trusted discovery inputs are required. Phase 12 first requires that the source projection fails to satisfy all supplied expectations, then checks the edited projection and the compiler. An unsupported projection or exceeded deadline produces an evidence status. Source diffs, source snapshots and explicit approval carry forward.

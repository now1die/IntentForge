# Cross-branch coordinated repairs

A bounded branch projection groups supplied examples by their actual CFG
edge trace. Single-site exploration runs first. If an edit fits every expected
output, Phase 9 leaves the existing single-edit mechanism in charge. For paired
repair, each literal edit must independently fix at least one failing example,
leave its sampled paths unchanged, and address path traces distinct from the
other site. The combined edits must satisfy every supplied example.

The search reuses lexical bindings and locates edits against the original
source. It is capped at eight sites, 96 single trials, 96 pair trials and two
nonoverlapping edits per proposal. It does not assume branches should have
the same formula. The paired correct controls preserve intentionally different
coefficients.

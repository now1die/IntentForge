# Architecture

Public engine `115` extends checked Phase 11 projection with explicit recursive call endpoints, duplicate minimum positions and lexical extrema. Candidates use source-located edits, compiler validation and reprojection with typed discovery inputs. Program facts are scoped to the observed inputs. The API sends candidate identities through the restricted worker and source-bound manual approval controls the apply path.

In development and preview the browser uses a same-origin `/api` bridge. Vite forwards only public workbench paths to FastAPI on loopback. The hosted app continues to mount its own `/api` route. Initial HTML gives troubleshooting guidance before React loads. The application loads inside a React error boundary.

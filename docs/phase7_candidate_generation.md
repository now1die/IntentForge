# Candidate generation

The existing compiler validation, lexical spans, deduplication, candidate attempt limits and shared analysis deadline apply to engine 7. The expanded rules reuse the Phase 6.5 recursive progress and test-guided operator categories. The guard identifies a parameter and indicates a direction. The one-unit step remains a hypothesis about the intended domain.

The final cohort yielded four compiler-valid code-only candidates and fourteen compiler-valid test-guided candidates. Each generated candidate used one edit. Guided exact reference recall was 6/19, and all six exact references matched their independently supplied vectors. Three passing repairs remained optional because the original reached the call-depth limit. The other thirteen injected faults had no exact synthesized candidate.

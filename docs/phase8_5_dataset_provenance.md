# Dataset provenance

The frozen data contains 36 records. The final split has 14 faults, 14
paired correct controls and two partial-specification controls. Development,
selection and calibration contain one pair each. No family spans partitions.

Four families adapt algorithms from TheAlgorithms/Python at
`30507bbe41397065728167fb09aa820f9fce8dc7`. The pinned source files and MIT
license are included with their SHA-256 digests. These are Mini-C adaptations
of overtime pay, ceiling, signum and abundance testing. Every scored fault
is project-injected. This cohort includes zero documented naturally occurring
upstream defects and received zero external human reviews.

Independent Python mathematical functions generate the expected outputs. The
evaluation cross-checks the correct Mini-C reference against those expectations
over both partitions. The records identify the reference source, assumed
domain, mutation origin and any known accepted alternate expression.

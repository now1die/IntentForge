# Candidate generation

The five repair categories are endpoint search, adjacent cell, rotation interval, checked zero guard and derived aggregate. The analyzer uses compiler-provided spans and lexical bindings, checks the complete candidate source, then projects every discovery expectation. The discovery report distinguishes agreement, no compatible edit, ambiguity, incomplete specification, unsupported projection and work limits.

The existing limits permit 24 trials and four new proposals, with at most two nonoverlapping edit sites in an atomic candidate. The shared model limits transfers to 650, entered iterations to 64 per loop and fixed layout to 32 cells per function. Runtime verification and source-snapshot approval use the established review pipeline.

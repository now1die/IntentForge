# Sentinel collisions

A negative literal default and an alternate reaching assignment may coexist at a comparison. If the assigned expression can equal the default, the debugger exposes possible collision separately from initialization and presence. Exact negative return values, zero data and true sentinel use are covered by controls and targeted tests.

A repair requires an existing Boolean flag initialized false and set true in the same branch as the value write. The flag and value must have the closed write pattern checked by the compiled bindings. Supplied examples and finite projection must support replacing a numeric equality test with the flag or its negation. Phase 12 adds no fields or flags. The archived JavaScript triplet needs container presence modeling beyond this pattern.

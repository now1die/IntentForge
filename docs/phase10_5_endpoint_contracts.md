# Endpoint contracts

From ordered observed cells, the projection compares supplied expected results to first and last exact match, first greater-than-or-equal position, first strictly greater position, and saturated variants. A unique supplied negative result may represent absence. Insertion position can equal the extent. A saturated endpoint is clamped to the last cell. Discovery examples may leave several contracts compatible, and the UI shows those alternatives.

Endpoint synthesis requires at least three observed input cases and duplicate evidence. Recursive refinements use the lexical endpoints, a checked midpoint and recognized tail-call updates. Exact-match refinement may continue across equal neighbors within a fixed extent. The abstraction covers physically fixed local arrays and admits empty logical searches through guarded paths. Pointer-based storage, general recursion and arbitrary array lengths lie outside this grammar.

# Domain guard repair

One integer parameter can support a pure entry test using < or >. At least
two distinct failing values on that axis must request the same typed sentinel.
An adjacent successful value with a different expected output anchors the
boundary. All supplied vectors on the guarded side must expect the sentinel.
Bounds metadata and unobserved regions supply no expected outputs.

The insertion is inside the selected function before its first original
statement. Programs with globals or unresolved effects abstain. The compiler
validates lexical scope and return type, and the isolated worker separately
checks the compiled candidate.

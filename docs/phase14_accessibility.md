# Accessibility and responsive interaction

Header and sidebar links share `aria-current`. A skip link focuses the workspace. The Compiler tabs support arrow, Home and End keys. Graph nodes and controls have accessible names and keyboard actions. Native review dialogs contain focus and close with Escape. Data tables use real headings and labeled input controls.

The sidebar icons scale on proximity without moving their hit areas. Transitions are brief and disabled by reduced-motion preferences. Narrow layouts stack panel columns and preserve horizontally scrollable code and input tables. Chromium checks cover focus, reduced motion and a 390-pixel viewport.

# Relational evidence

A fact records its compiler span, function, lexical names and identifiers, assumptions, a finite observation set and a hypothesis where applicable. Each observation records the supplied input number and a bounded CFG path. Compiler evidence includes typed integer storage and fixed declared extents. Ordered cells, denominator values, cyclic descents and verified helper results stay scoped to the observed inputs. A missing observation remains unknown.

The observer records up to 32 branch outcomes per function and sample, up to 12 distinct helper calls or results per function and sample, and up to 48 public facts. The inherited compiler-backed projection has a joint deadline and capped transfers, loops, function frames and storage. Globals, unknown effects, missing cell facts, unproved progress and unsupported arithmetic cause abstention or an explicit sample issue.

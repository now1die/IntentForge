# Duplicate cyclic minima

The model links a scalar logical length to the upper endpoint and checks values inside fixed physical storage. A sample must have at most one cyclic descent. Recorded minimum positions are compared with the supplied position and its first occurrence.

The new edit repairs the cyclic seam when the original finds a later minimum equal to the first cell and the expected contract calls for position zero. Cases include empty, singleton, two, three and larger prefixes, all-equal arrays, interior duplicates and smaller inactive cells. Examples that allow different tied minima do not warrant a first-minimum edit.

The archived three-branch short rotation needs different neighbor guards and multiple progress changes. That implementation remains outside the supported binary pivot form.

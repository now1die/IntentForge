# Behavioral repair review

The existing intention engine produces and ranks alternatives. Up to four candidates validated by the compiler run against the same supplied tests as the original. The response retains static rank and static evidence independently of observed agreement. When the original mismatches or has a located runtime failure, the separate review order can promote passing candidates. A comparison can report multiple matches, one match or no observed match. A passing result covers the supplied examples.

Select a candidate to compare its source and execution evidence with the original. Only explicit approval applies the edit through the existing source-checked editor path. Changing source, entry point, vectors, limits, tracing or candidate options invalidates the snapshot. Changing language removes the Mini-C workbench controls.

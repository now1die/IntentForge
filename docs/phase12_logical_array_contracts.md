# Logical array contracts

A constant allocation gives a physical extent. A lexical input length used by a unit-step prefix scan supplies a candidate logical contract. A sampled logical length is admitted only within the physical extent. The candidate active prefix is half-open, from zero to length. The inactive suffix can contain prior data and either interval can be empty.

A return reached through a guaranteed zero-length comparison has no active data from that prefix. If the return directly reads the array without effects, Phase 12 withholds inherited edits to that read and can substitute an agreed result constrained by the supplied empty-input examples. The archived offset patch is the regression case. A scan may be a partial view of a larger sequence, so an inferred prefix relationship does not prove the intended contract. Implicit lengths, changing length bindings and general missing-guard insertion remain outside the repair grammar.

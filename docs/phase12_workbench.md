# Phase 12 workbench

The Intention tab exposes static source evidence and a complete repair diff. Phase 12 evidence shows lexical bindings, spans, CFG sites, initialization, optional presence, logical array extent, physical capacity and coordinate assumptions. The interactive panel can run local discovery comparisons when the restricted worker is available. Independent evaluation outcomes are available in the benchmark reports.

Changing source invalidates reviewed candidates. Changing the interactive vectors invalidates their associated review. The compiler stays usable in analysis-only mode. Startup distinguishes a failed entry script from a failed dynamic import using static HTML and the React error boundary. Reload remains available.

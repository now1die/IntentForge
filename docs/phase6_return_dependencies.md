# Return dependencies and coordinated edits

Phase 6 can propose a later computed binding when the same earlier local reaches one or two pure-identifier returns. The alternative must be a unique visible same-type terminal from a chain of at least two pure arithmetic declarations. The original binding must have the same unique reaching definition at the first dependent computation and at the affected returns. The terminal must be unused. Calls, array access, global writes, divergent or ambiguous alternatives and late writes to the original binding make this rule abstain.

Two marks produce a single proposal with two nonoverlapping edit spans. The candidate exposes both the computation evidence and the possibility that returning the intermediate value was deliberate. A legitimate intermediate-return control in the corpus exercises that limitation. The analyzer can represent more return dependencies than this narrow synthesis rule can repair.

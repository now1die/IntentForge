# Execution and approval boundaries

The ordinary API performs bounded typed projection over compiler CFGs. Candidate runtime checks use the direct loopback gateway and the owner-only directory containing its private Unix socket. The disposable Linux worker runs non-root, with a read-only filesystem, seccomp, disabled networking, dropped capabilities and bounds on CPU, memory, processes, wall time, vectors and candidates. The worker shares a 200,000-step VM budget across the batch.

Public profile `105` uses the existing private profile `8` for the worker batch. The boundary verifies source and response identity and requires approval before applying any source edits. Public execution is disabled. Full C goes through Clang analysis. `LIVE_OLLAMA_STATUS=NOT_VERIFIED`.

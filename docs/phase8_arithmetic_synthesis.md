# Arithmetic synthesis

The grammar changes nearby literals by one or two, adjusts a multiplicative identifier by one, drops an existing unit offset, swaps operators within their precedence class, or targets a unique initialized return dependency. It bounds arithmetic nodes to 160, expression depth to 14, helper depth to two, trials to 144 and new proposals to four. The compiler attempt budget remains shared with earlier generation.

The search prioritizes smaller token changes before applying the established deterministic order. The 22 generated arithmetic proposals were compiler-valid and used one edit each. Seventeen changed one token and five changed five tokens. The model leaves grouping rewrites, unrestricted algebra and coordinated new multi-site edits outside this profile. Existing repair categories, including historical multi-site edits, remain available.

# Candidate generation

Phase 11 adds interpolation relationships, zero-magnitude helper guards, cyclic tie refinement and coordinated range repair. It also restores endpoint hypotheses after supported scope-preserving rewrites. A trial is limited to one or two nonoverlapping source sites. Every candidate is validated as a complete source snapshot and must match each supplied typed output under checked projection.

The existing limit is 24 trials and four proposals per pass. Projection uses up to 650 transfers, 64 entered iterations per loop, and 32 fixed cells per modeled function. Discovery-compatible edits remain proposals until independent worker verification and user review. Ranking is deterministic.

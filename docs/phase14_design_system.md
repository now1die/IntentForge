# Burgundy Cream design system

The four brand tokens are `#800020` primary, `#D45060` accent, `#F3E6D5` warm surface and `#FFF9F2` background paper. Supporting colors distinguish green success, red errors and amber unverified or unavailable states. The Monaco theme uses `#301019` with cream text, pink keywords, gold numbers and a distinct gutter.

The interface bundles Plus Jakarta Sans under the SIL Open Font License and uses the existing Geist Mono for code. Original crosshatched SVG illustrations depict a terminal, a magnifier examining a program decision, a technical notebook with instruments and a programming textbook.

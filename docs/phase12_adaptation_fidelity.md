# Adaptation fidelity

Jump search keeps both loops over sorted, distinct active prefixes of length zero through four. The Mini-C stride rule implements the same integer square roots across that finite domain. The upstream empty-list `IndexError` corresponds to a checked Mini-C `ARRAY_BOUNDS` outcome. Inactive cells are physical data only.

The CycleSort adaptation retains the swaps, position scans and write count over four distinct signed inputs. It preserves the erroneous numeric count. It projects the earlier algorithm's corrected returned array to its first cell, since the executable scalar interface cannot return an array.

# Adaptation fidelity

The pinned Python source executes under Python, the JavaScript pair runs under Node with its archived dependency resolved as ESM, and Java compiles and runs in a separate temporary directory. Raw before-and-after outcomes matched Mini-C on 24 distinct family inputs, or 48 revision-specific comparisons. Each corrected revision also agrees with the independent expected outputs.

The Python adaptation inlines pure reads over its sorted domain. The JavaScript adaptation keeps the original trial divisor and fixed Euclidean behavior over signed integers. The Java adaptation bounds operands so the fixed long arithmetic fits signed Mini-C values. Java arithmetic exceptions are mapped to the corresponding Mini-C arithmetic issue.

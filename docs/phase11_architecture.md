# Architecture

Public profile `11` layers bounded relational reasoning over the existing typed AST and CFG projection. It uses the compiler's lexical storage and spans, reaching definitions and checked interval progress. The projection produces evidence and can identify narrowly scoped candidate changes. Each complete candidate compiles and is projected afresh on the discovery inputs.

The static profile is opt-in. Behavioral comparison routes candidates through the private worker. The application uses source identities, the established evidence classification and explicit review to determine how the source diff may be applied. The new profile uses the existing private worker batch version.

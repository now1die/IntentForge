# Phase 7 readiness

Phase 6.5 supports continued opt-in experimentation. On the admitted final cohort, supplied expectations recovered two more exact repairs while introducing candidate alerts for four correct controls. A future experiment should test gating alternatives on observed original mismatches under the existing worker boundary and measure both false alerts and lost repairs.

Before a broader release, enlarge the independently adjudicated selection and final partitions, add helper-mediated and nonunit progress faults, and design bounded probes that exercise both a branch threshold and its value-driving arguments. The current final probes separated zero additional pairs. Equivalent branch rewrites and added shadow scopes also exposed candidate loss in the narrow source grammar. Improving those failure cases is a stronger next experiment than changing static ranking on the present sample.

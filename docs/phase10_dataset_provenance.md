# Dataset provenance

Corpus v1 contains 28 cases. Development, selection and calibration each have one fault/control pair. The final set contains four documented upstream faults, five injected faults and thirteen correct controls. Each upstream project appears only in the final partition. The fresh final split is separate from the four archived diagnostics.

The manifest preserves parents, fixes, source paths, the case-file SHA-256 and SHA-256 hashes for the upstream archive, dependency and MIT license files. Expected values use independent executable functions, including tuple indexing, `bisect_left`, `math.lcm`, minimum-position selection and arithmetic references. Independent human adjudication was unavailable.

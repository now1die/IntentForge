# Workbench

The Intention inspector offers Phase 6.5 as an explicit profile. Expand a function to inspect modeled return paths, call arguments and offsets, possible return parameter dependencies, base guards and recurrence structure. Withheld return hypotheses carry their own explanation. Candidate review shows the evidence basis, source edits and approval action.

The local behavioral panel offers the same profile alongside the existing restricted capability gate. It displays original and candidate outcomes, static rank, behavioral review order, source diff, test observations, runtime limits and ambiguity. Changing the profile or tests invalidates the displayed evidence. Monaco keeps the original source until approval.

# Research Lab

Run analysis on the shared source and select a research profile. The default reads the most recent suitable Compiler or Intention result. The graph and AST expose program structure. Program State combines bounded initialization and array facts with the compiler symbol table. Dataflow lists reaching definitions for returns. Relationships shows the call and recursion summaries and available relational constraints. Candidate Evidence reports the ranking, facts and raw engine response.

Verification Results shows the original and candidate observations collected in Intention. The historical workbench retains detailed interactive tracing, limits, probes, Clang evidence, ranked correction internals, historical profiles and recorded demonstrations. Benchmark summaries and the ablation table load the frozen reports directly.

# Phase 8 architecture

Engine 8 adds typed input constraints and arithmetic witnesses to the existing compiler and deterministic candidate pipeline. The engine builds a bounded term projection from a straight-line CFG and lexical scalar definitions. Existing interprocedural witnesses admit small pure helpers. The projection estimates which one-site alternatives fit supplied expectations. The shared compiler validates accepted proposals and the existing ranker orders them.

Behavioral verification reuses the local gateway and disposable Mini-C worker. Private profile 8 carries an optional typed domain and uses the existing ranked probe algorithm, admitting only inputs in that domain. Earlier private requests omit the field. The worker's completed observations govern confirmed faults and review eligibility. Static arithmetic results remain labeled as hypotheses.

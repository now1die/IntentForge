# Ranking selection policy

Freeze the fixtures and leakage policy before running final engine experiments. Evaluate every ordering on one candidate pool. The opt-in Phase 5.5 configuration uses all four conservative evidence gates and retains the Phase 5 deterministic ordering. Deployment would require a positive ordering gain on independently separated selection families with no increase in wrong recommendations or control alerts. A tie or insufficient eligible pool coverage retains deterministic ranking. Final outcomes are reported for the selected configuration without retuning. No new learned model or calibration curve is fitted in this phase.

Keep the earlier engine versions available. Phase 5.5 remains opt-in while evaluation evidence is limited. Approval is always a separate user decision.

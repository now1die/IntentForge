# Expanding windows

The model tracks a positive growth step with a fixed-array guard such as `width < length`, then checks both the growth and the later shrinking interval on each input. Supported growth factors range from two through eight. A repair can change an existing handoff expression while retaining its clamp.

The two-site repair combines a handoff offset with a stable absent result. It requires a trusted negative sentinel and at least two distinct nonnegative hit results. Both edits must agree with the same supplied examples and are reviewed together. The archived doubling case and a new tripling fixture exercise this path. Arbitrary stop conditions and arbitrary sentinel formulas fall outside this model.

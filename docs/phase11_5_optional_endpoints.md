# Optional and concrete endpoints

An explicit signed recursive upper argument can be negative after decrementing a bounded zero-origin interval. This concrete value belongs to the empty-interval path and is separate from optional initialization and a supplied no-match result.

The rule uses an existing checked recursive base, a single preceding reset of the upper binding to the extent, typed explicit call sites and sampled valid root calls. A negative nested bound can justify removing the reset when the complete edited source matches discovery. The archived exponential-search failure is recovered by that edit. Optional root entries, effectful initialization and arbitrary negative coordinate conversions stay outside the rule. Separate controls exercise signed coordinates, negative sentinels and zero insertion indexes.

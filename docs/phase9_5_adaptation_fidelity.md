# Adaptation fidelity

The Java search benchmarks use fixed-length sorted arrays with unique
integer keys. The translations preserve recursion or doubling, the inclusive
or exclusive input bound, and the original out-of-range failure or negative
insertion index. The Smith-number specimen retains trial division, digit
sums and the composite restriction over the declared small integer domain.

The JavaScript multiple-sum specimen extracts the unchanged numeric body and
omits CLI I/O. The date specimen accepts valid date components and uses exact
rational scaling for the original final floor. The corrected specimen applies
each positive-term truncation separately.

Direct Java and JavaScript replay matched defective and corrected Mini-C
outcomes at 39 paired inputs. Independent expected values verified both
translations. The provenance replay covers holdout for fidelity verification.
Repair synthesis receives discovery only.

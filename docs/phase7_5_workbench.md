# Workbench

Choose Phase 7.5 in the Intention pane to inspect guarded parameters, threshold and argument relationships. A modeled recursive call shows its constant offset or symbolic step and its relationship to the return. The Examples mode can generate additional hypotheses and shows supporting evidence, counter-evidence, compiler validity and a source diff.

The local Behavioral verification pane offers Phase 7.5 with the existing verified-original states, static rank and behavioral review order. Changing inputs, source, function, engine profile or execution settings invalidates the displayed evidence. Candidate review and explicit approval are separate actions.

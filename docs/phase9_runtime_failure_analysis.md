# Runtime-failing originals

The static model localizes projected binary integer failure and describes the
operator, operands, supplied-input position and source range. It can follow
a small reaching-term slice from the failure to an upstream declaration.
Candidate generation requires at least one supplied input for which the
original projection produces a value and a bounded single edit that satisfies
every trusted expectation.

The isolated worker alone supplies observed runtime evidence. The gateway
checks source and vector identities before returning the worker's issue, source
span and triggering vector. It reports completion and expected-output agreement
separately for alternatives. Runtime failure remains distinct from confirmed
output mismatch and does not qualify on its own for a recommendation. Array
bounds errors, nontermination and unchecked model failures remain unsupported
for this synthesis mechanism.

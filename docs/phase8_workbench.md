# Workbench

Use Phase 8 in the Intention pane to see signature, trusted example count, partial coverage, input domain and arithmetic model status. Review a hypothesis to see its supporting evidence, counter-evidence and exact source diff. The regular workspace shows only independently supplied examples.

The Behavioral verification pane offers the same opt-in profile. Matching originals keep the optional repair list collapsed. Expanding it reveals the existing candidate pool. A confirmed mismatch shows runtime evidence, review order, test agreement and explicit approval. Source, function, domain, vectors, profile and execution settings invalidate prior evidence.

# Phase 9.5 workbench

Choose **Phase 9.5 control-flow repair** and supply typed examples. The
evidence view shows guard thresholds and sentinels, loop origins and latches,
checked indexed bindings, sampled endpoints and projected helper calls or
exits. Candidate details show the replacement and resulting sampled indices.

Local behavioral comparison displays the existing verified verdict and review
eligibility. Changes to a source or verification setting invalidate the
corresponding preview. A repair applies only on explicit approval against
the current snapshot.

# Dataset provenance

The version 1 freeze contains ten final programs, one development control, and one selection control. The final cohort includes two documented defect adaptations, three authored injected faults and five paired correct controls. Related versions use the same partition. Earlier phases and archived diagnostics retain their existing datasets.

The external sources are the [empty jump search change](https://github.com/TheAlgorithms/Python/commit/13f71409f675eec1c59aef6ff2bac9d3b2a74617) and the [cycle sort return change](https://github.com/TheAlgorithms/JavaScript/commit/0da3880955e0641b4d6b34782bd3892cb4b08802). The [manifest](../benchmarks/phase12_data/manifest-v1.json) pins both before-and-after pairs, path names, licenses and archived source hashes. Independent human review was unavailable.
